# realtime-bigdata-pipeline
Real-time big data pipeline using Kafka, Spark, and Airflow with end-to-end processing and analytics

## Overview
This project builds a real-time data pipeline using Apache Airflow and Docker for orchestrating workflows and processing structured data.

## Tech Stack
- Apache Airflow
- Docker
- Python

## Features
- Automated workflows using DAGs
- Scalable pipeline design
- Containerized setup

## Project Structure
- airflow/dags/ → pipeline workflows
- data/seeds/ → input datasets
- docker-compose.yml → services setup

## How to Run
1. Clone repo
2. Run:
   docker-compose up
3. Open Airflow UI:
   http://localhost:8080
